# packages/ios — Claude Code Guide

Native iOS/iPadOS app (SwiftUI + the Kotlin Multiplatform `Shared` framework from [`../shared/`](../shared/)). Active plan: the `MK.iOS.*` block in [PRODUCTION_PLAN_NATIVE.md](../../PRODUCTION_PLAN_NATIVE.md).

**Before editing under `../shared/`, invoke the `native-android-mk` skill** (repo rule — it covers KMP schema/threading discipline too). IPTV protocol questions: `iptv-domain` skill.

## Stack

- **Swift 6 / SwiftUI**, iOS 17+, iPhone + iPad (`TARGETED_DEVICE_FAMILY 1,2`)
- **XcodeGen** — `YancoTV.xcodeproj` is generated from [project.yml](project.yml); edit the yml, then `xcodegen generate`. Never hand-edit the pbxproj.
- **Kotlin `Shared` framework** — static, built by the "Build Shared KMP Framework" pre-build phase via `../android/gradlew :shared:embedAndSignAppleFrameworkForXcode`. Business logic (parsers, Xtream/Stalker clients, repos, backup) comes from there; Swift code renders it.
- **No third-party Swift dependencies** without strong justification.

## Build / run

```bash
# Regenerate the Xcode project after any project.yml change
cd packages/ios && xcodegen generate

# Simulator build (no signing, no developer account needed)
xcodebuild -project YancoTV.xcodeproj -scheme YancoTV \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' build

# Kotlin framework alone (from packages/android/)
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :shared:checkIosCompile
```

- `JAVA_HOME` must point at a JDK 17 (Homebrew: `/opt/homebrew/opt/openjdk@17`); the pre-build phase falls back to that path when Xcode strips the env.
- Gradle needs an Android SDK for configuration even for iOS-only tasks — `packages/android/local.properties` must carry `sdk.dir` (machine-local, gitignored).
- **Signing:** simulator builds need none. Running on a physical iPhone/iPad or as "My Mac (Designed for iPad)" needs a Team selected in Xcode (Signing & Capabilities) — a free personal team works until the paid membership is active. XcodeGen regeneration drops the team; re-pick it after `xcodegen generate` when device-testing.
- **Mac:** runs today via the "My Mac (Designed for iPad)" destination on Apple silicon. A native macOS target is a possible later milestone (needs `macosArm64` actuals in `../shared/`).

## Bridge notes (Kotlin → Swift)

- Kotlin top-level functions surface on file-facade classes: `parseM3u(...)` in `M3uParser.kt` → `M3uParserKt.parseM3u(content:logger:)`; `NOOP_LOGGER` in `Logger.kt` → `LoggerKt.NOOP_LOGGER`.
- Kotlin default arguments do not cross the bridge — pass every parameter explicitly from Swift.
- `List<T>` arrives as a typed Swift `Array`; Kotlin `data class` fields arrive as properties.
- The framework is rebuilt by the pre-build phase on every Xcode build; a Kotlin edit needs no manual Gradle step.

## Hard rules

1. **Shared logic lives in `../shared/`** — if Swift code starts re-implementing a parser/classifier/repo, stop and use (or extend) the KMP module instead. Rule 8 in [AGENTS.md](../../AGENTS.md).
2. **Credentials go in the iOS Keychain** (MK.iOS.2) — never UserDefaults, never SQLite, never logs. Mirror `redactCredentials` behavior at every rendering site.
3. **ATS/cleartext:** `NSAllowsArbitraryLoads` is on, as the deliberate iOS half of the cleartext threat-model decision in [AGENTS.md](../../AGENTS.md) — providers serve plain HTTP and the host set is user-configured at runtime, so a static ATS exception list cannot be written ahead of time. **The other half is missing:** Android backs this with an application-layer allow-list seeded from the `sources` table (MK.SEC.A/B/C, MB-203); iOS has no equivalent yet (MK.iOS.SEC). Until it lands, flag any new plain-HTTP call site in review, and never add credential-bearing HTTP outside a user-configured provider host.
4. **Playback goes through `PlaybackEngine`** — never talk to `AVPlayer` or `VLCMediaPlayer` from a view. Same rule as desktop's `IPlayer`. `PlaybackController` owns one engine at a time and swaps it; `EngineRouter` picks, and an unsupported-format failure promotes to VLC once.
5. **VLCKit is LGPL.** Keep it dynamically linked, never re-target it as a static archive, and never swap in a custom libVLC built with GPL modules — that would pull YancoTV itself under GPL. See [docs/LICENSES.md](../../docs/LICENSES.md).
6. **One `MK.iOS.*` sub-task per commit.** Don't push without an explicit ask.
7. **No feature work outside the active plan** — amend PRODUCTION_PLAN_NATIVE.md first.
